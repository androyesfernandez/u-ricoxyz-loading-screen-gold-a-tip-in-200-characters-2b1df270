**Loading Screen Gold** — one sharp, funny loading-screen tip for stressed
developers and AI coding agents, 200 characters or fewer. `main.ts` (Node 22)
writes a single line — no trailing newline — to `/output/entry.txt`:

> Tip: you pasted the agent's code without reading it. The agent wrote it
> without reading yours. Between you, a function now exists that neither of
> you understands. It works. Do not touch it.

The line is 189 characters (189 bytes): one concrete scene, held to the end.
The developer pasted the agent's code unread; the agent wrote it unread; the
result is a function neither of them understands that works anyway — and the
only sane advice left is not to touch it. Both sides of the pair feel seen.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```

Deterministic, no network, no input. See `duel-test.md` for the 16 drafted
candidates and the full proxy-duel results that picked this line.
